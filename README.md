# InternStudio - Data Science Task 1
### Enterprise Data Analysis Project

This repository contains the solution for InternStudio Data Science Internship - Task 1.

#### 📁 Files Included
- `Student_work_file (1).ipynb` - Main Jupyter Notebook with complete analysis
- `enterprise_database (1) (1).db` - SQLite database with enterprise data
- `daily_exchange_rates (1).csv` - Daily currency exchange rates

#### 🎯 Project Objective
To perform exploratory data analysis and extract business insights from enterprise database using Python, SQL, and Pandas.

#### 🛠️ Tech Stack Used
- Python (Pandas, NumPy, Matplotlib)
- SQLite / SQL
- Jupyter Notebook
- Git & GitHub

#### 📊 Key Analysis Performed
- Database connection and schema exploration
- Data cleaning and preprocessing
- SQL queries for data extraction
- Exchange rate handling and currency conversion
- Business insights generation

#### 🚀 How to Run
1. Clone the repository
2. Open `Student_work_file (1).ipynb` in Jupyter Notebook / VS Code
3. Install required libraries: `pip install pandas numpy matplotlib`
4. Run all cells
